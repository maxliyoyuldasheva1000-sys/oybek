⌨️ Klaviatura tezkor tugmalari

Tezkor tugmalar ishni tez va qulay bajarishga yordam beradi.

🔹 Asosiy Ctrl tugmalari

  • Ctrl + A — Hammasini belgilash
  • Ctrl + C — Nusxa olish
  • Ctrl + V — Qo‘yish
  • Ctrl + X — Kesish
  • Ctrl + Z — Bekor qilish
  • Ctrl + Y — Qayta tiklash
  • Ctrl + S — Saqlash
  • Ctrl + P — Chop etish

🔹 Matn bilan ishlash

  • Ctrl + B — Qalin (Bold)
  • Ctrl + I — Egri (Italic)
  • Ctrl + U — Ostiga chizish

🔹 Shift tugmalari

  • Shift + harf — Katta harf
  • Shift + Tab — Oldingi katakka o‘tish

🔹 Enter va Tab

  • Enter — Yangi qator
  • Tab — Keyingi katakka o‘tish

🔹 Maxsus tugmalar

  • Caps Lock — Katta harflarni yoqish
  • Backspace — Orqaga o‘chirish
  • Delete — Oldingi belgini o‘chirish
  • Insert — Qo‘shish / almashtirish rejimi

🔹 Boshqa foydali tugmalar

  • Alt + Tab — Ochiq oynalar orasida almashish
  • Ctrl + Alt + Delete — Xavfsizlik oynasi
  • Windows — Start menyu

🔹 Asosiy kombinatsiyalar

  • Win – Start menyuni ochadi
  • Win + D – Ish stolini (Desktop) ko‘rsatadi/yashiradi
  • Win + E – Fayl menejeri (This PC) ni ochadi
  • Win + L – Kompyuterni qulflaydi
  • Win + I – Sozlamalar (Settings) ni ochadi
  • Win + R – Run oynasini ochadi
  • Win + S – Qidiruv (Search)
  • Win + A – Tezkor sozlamalar / Bildirishnomalar

🔹 Oynalar bilan ishlash

  • Win + Tab – Ochiq oynalar va virtual ish stollari
  • Win + ↑ – Oynani kattalashtiradi
  • Win + ↓ – Oynani kichraytiradi
  • Win + ← / → – Oynani chap/o‘ng tomonga joylaydi
  • Win + M – Barcha oynalarni kichraytiradi
  • Win + Shift + M – Kichraytirilgan

🔹 Virtual ish stollari

  • Win + Ctrl + D – Yangi ish stoli yaratadi
  • Win + Ctrl + ← / → – Ish stollari orasida o‘tish
  • Win + Ctrl + F4 – Joriy ish stolini yopadi

🔹 Skrinshot va yozib olish

  • Win + PrtSc – Ekran rasmini saqlaydi
  • Win + Shift + S – Ekranning bir qismini rasmga oladi
  • Win + G – O‘yin paneli (screen recording)

🔹 Boshqa foydali tugmalar

  • Win + X – Tezkor menyu (Power User Menu)
  • Win + V – Clipboard (nusxa olinganlar tarixi)
  • Win + . (nuqta) – Emoji va belgilar 😄
  • Win + K – Qurilmalarga ulanish
  • Win + P – Proyektor / ikkinchi ekran sozlamalari
